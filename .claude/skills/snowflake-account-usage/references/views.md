# View catalog

One row per view or command. Checked against docs.snowflake.com on 2026-09-28; rows added 2026-09-29 were checked the same day. "not stated" means the docs page does not say.

Abbreviations:
- AU = SNOWFLAKE.ACCOUNT_USAGE, OU = SNOWFLAKE.ORGANIZATION_USAGE, DSU = SNOWFLAKE.DATA_SHARING_USAGE.
- LTZ = TIMESTAMP_LTZ.

Defaults:
- AU historical views keep 365 days.
- "Whole account" means any role granted the view sees every row.
- "Role-filtered" means the view returns only objects the current role can access.
- Visibility names the SNOWFLAKE database role. IMPORTED PRIVILEGES on SNOWFLAKE grants all of them.

Traps are in `traps.md`.
