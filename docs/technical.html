Technical view · for engineers

Snowflake audit app

What it is

  • A read-only audit of one Snowflake account: 306 SQL checks in 7 domains read ACCOUNT_USAGE and ORGANIZATION_USAGE.
  • Pipeline: export, results folder, loader, DuckDB file, FastAPI, React. The app itself never connects to Snowflake.
  • Runs on the user's machine; an optional Streamlit in Snowflake build ships the same API and UI.

Probe every view with LIMIT 0 before running checksan unreadable view must read NOT_ASSESSED, not empty
Export to a folder, load to DuckDB, serve from the filethe app never needs a Snowflake connection; the folder can be moved as a zip

Status and waste computed at read time with floors and capsexported status stays raw; thresholds change without a re-export
