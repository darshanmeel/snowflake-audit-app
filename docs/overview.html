Snowflake audit app

A read-only check-up of a Snowflake account: where the credits and dollars go, what looks wasted, and how things are set up.

What it is and who uses it

What it does

  • Runs 298 checks on your Snowflake usage records.
  • Shows spend, possible waste and set-up gaps in one place.
  • Never changes anything in your account.

Who uses it

  • Platform owners: sizing, idle machines, failing jobs.
  • FinOps (cloud cost owners): spend, budgets, chargeback.
  • Security and governance: access, sensitive data, audit trail.
  • Data engineering leads: tasks, loading, slow queries.

Why it exists

  • Snowflake bills by usage, so waste is easy to miss.
  • The answers sit in many separate usage views.
  • This app collects them and ranks what to fix first.

How it works

Key: solid arrow = request to Snowflake · dashed = data moves · grey box = data · dashed grey box = option.

19 top-level tabs. Money, waste and change are always shown apart and never added together.

Value: a real-world scenario illustrative

  • Monday: a platform owner runs the export and opens the app. It takes minutes, not a week of report writing.
  • Overview shows a warehouse that stays on all night with no queries: about 7 hours idle each day.
  • The money pages show three separate numbers, never one blended total.

What it needs

  • A Snowflake role that can read the usage views, granted once by an administrator.
  • A normal laptop or server with Python and a browser. No other service.
  • Without full access, 85 checks fall back to narrower sources. Others show a dash with the reason.

Risks

RiskImpactWhat to do
1. Numbers lagSnowflake publishes usage with delays of hours; billing views lag up to 72 hours. Today is shown as partial.Read the last full days; re-run to refresh.
2. Some checks need moreHigher Snowflake edition or extra privileges are needed for some areas; those show a dash, so the picture can be incomplete.Check the coverage count: "checks that ran" out of 298.
3. Prices are estimatesDollars come from the contract rate sheet if readable, else the last 90 days of invoices, else a default ($3.00 per credit). Defaults can be off.Make the rate sheet readable, or set your real price.
